# 소장 · 나만의 음악

Doppler의 로컬 음악 보관 방식과 Doppi의 간결한 재생 경험을 참고한 개인 음악 플레이어 PWA.

## 아이폰 사용
1. 배포 주소를 Safari에서 열고 본인 ChatGPT 계정으로 로그인합니다.
2. 공유 → 홈 화면에 추가.
3. 홈 화면 앱에서 음악 가져오기 → 파일 앱의 MP3/M4A 등을 선택합니다.
4. 재생 화면, 좋아요, 셔플, 전체/한 곡 반복, 검색, 최근 재생, 제목/아티스트/커버 편집을 사용할 수 있습니다.

음악 파일과 커버는 IndexedDB에만 저장되며 서버 업로드나 기기 간 동기화가 없습니다. 예시 음악 `초록빛 오후`는 이 프로젝트에서 직접 합성한 18초 피아노풍 멜로디입니다. 버튼으로 선택해서 추가할 수 있습니다.

## 한계
- 네이티브 iOS 앱이 아닌 설치형 웹앱입니다.
- 최초 로그인/접속에는 인터넷이 필요합니다. 서비스 워커가 앱 파일 준비를 마친 후 오프라인 셸과 저장 음악을 사용할 수 있도록 구성했습니다. 실제 iPhone에서 비행기 모드 실행 확인이 필요합니다.
- iOS의 잠금 화면과 백그라운드 재생, 지원 오디오 형식은 Safari/iOS 정책에 영향을 받습니다. Media Session API 지원 범위 내에서 잠금 화면 제목과 재생/넘김 동작을 연결합니다.
- 음악은 브라우저/홈 화면 환경별로 저장되며 자동 동기화되지 않습니다. 브라우저 데이터 삭제, 앱 제거, OS 저장 공간 정리로 없어질 수 있으므로 원본은 보관하세요.
- 아이폰 웹앱에서는 음량을 기기 버튼으로 조절합니다.
- Google Fonts는 초기 접속 시 로드하며 오프라인에서는 시스템 글꼴로 표시될 수 있습니다.

## 로컬 실행
`python3 -m http.server 4173 --directory dist`

## 검증
JavaScript 구문 확인, 390×844 화면, 합성 WAV의 실제 재생 상태와 18초 길이, 좋아요 및 곡 데이터의 새로고침 후 유지, 모바일 전체 재생 화면을 브라우저에서 확인했습니다. 실제 아이폰 하드웨어 검증은 수행하지 않았습니다.
